# FreeOmega domain soundness: design review

Status: **design proposed, awaiting acceptance**. Source baseline: `3120df0`.
This review introduces no Rocq definitions, instances, axioms or theorems.
It precedes Gate D. Implementation proceeds in separately accepted stages;
neither StateInterp nor another probability-directory reorganization starts here.

## 1. Objective and the necessary qualification

Provide an independent standard subprobability domain, then prove that the
probabilistic part of FreeOmega denotes into it. Soundness is required;
completeness of the syntactic quotient is not.

An unconditional function from **every raw** `FreeOmega MN A` to that domain,
with an unconditional supremum equation for every `FOLub`, is not the right
statement. `Definition.v` permits arbitrary sequences. For example, alternate
`FORet false` and `FORet true`. No subprobability measure can dominate both
Dirac measures in the setwise order: the disjoint Boolean singletons would
each have mass at least one.

The existing SubEnum evaluator `free_omega_upper` does have a meaning for this
raw term, namely `f |-> max (f false) (f true)`. But it is not additive:
on the two singleton indicators it gives one each, and on their sum it gives
one, not two. Bounded mass alone does not make a functional a measure.
This is a mathematical counterexample in this review, not a new checked
regression. `UpperExpectation.v` already documents this distinction.

Consequently the public mathematical claim should be:

```text
admissible FreeOmega representation -> standard subprobability value
```

Do not change raw syntax or the existing quotient just to put a proof into
the `FOLub` constructor. First prove admissibility of the representations
actually generated by primitive approximation and complete stable hitting.

## 2. Proposed independent domain

Use bounded expectation functionals over MathComp real numbers as the first
presentation. Write `I = [0,1]`, `Test A = A -> I`. An `OmegaVal A` contains
an evaluator `L : Test A -> I` satisfying:

- `L 0 = 0`;
- monotonicity in the test;
- positive homogeneity `L (c * f) = c * L f`, for `c` in `I`;
- additivity `L (f + g) = L f + L g` when pointwise `f + g <= 1`;
- monotone continuity `L (sup_n f_n) = sup_n L(f_n)` for increasing tests.

Addition in this law is ordinary real addition under its stated bound, not
silently truncated addition. `mass L := L 1 <= 1`; mass need not be one.
Equality is extensional equality of evaluators, not equality of proof fields.

Define independently of FreeOmega:

```text
bottom(f)       = 0
ret(a)(f)       = f(a)
L <= M         iff forall f, L(f) <= M(f)
(lub L_n)(f)   = sup_n L_n(f)             [L_n increasing]
(bind L k)(f)  = L(fun a => k(a)(f))
```

The domain construction must prove closure of these operations, the least
upper bound property, monad laws, and continuity of bind in both arguments.
Joint diagonal continuity follows from the two continuity results and
monotonicity; it must not be added as an uninhabited class assumption.

The standard-measure anchor is part of the work, not a naming convention:
construct `measure_L(U) := L(indicator U)`, prove countable additivity and
mass boundedness, and prove that its integral on bounded tests recovers `L`.
Conversely integration against a standard subprobability measure gives such
a functional. A thin abstract interface may expose the resulting operations,
but its first concrete implementation must be proved before claiming a model.

Use the powerset sigma-algebra for this arbitrary-`Type` presentation. This
supports empty carriers, arbitrary continuations, and high-universe stable
heads without declaring them countable. It does **not** assert that arbitrary
functions on an arbitrary measurable space are measurable. The analytic
adapter must respect the actual measurable-space choice.

Dependencies: the independent domain may use MathComp analysis and general
mathematical infrastructure, but must not import `Prob/FreeOmega`, PTree,
stable hitting, or `peutt`. Backend adapters depend on the domain, not vice
versa. Preserve the existing low native / high result universe separation.

## 3. Native interpretations

### SubEnum first

For a finite rational subdistribution `mu`, define

```text
native(mu)(f) = sum_(p,a in subenum_raw mu) real(p) * f(a).
```

Prove its domain laws, invariance under native equality, return/bind equations,
AE soundness and native coupling soundness. Rational weights are embedded
into the reals; the domain's values are not restricted to rational numbers.
Raw `Enum` needs individual mass-validity hypotheses and is not automatically
a subprobability model.

### MathComp adapter, separately qualified

The current `MathComp/Kernel.v` already uses fully discrete measurable
carriers `mc_carrier A`, not arbitrary standard Borel spaces. Its equality
ignores the bookkeeping point `MCBottom`. The intended evaluator is therefore

```text
native(mu)(f) = integral(root mu, extend f)
extend f MCBottom    = 0
extend f (MCValue a) = f(a).
```

Counting mass at `MCBottom` would be wrong: native zero is represented by a
Dirac at that point. Prove the adapter's equations against the existing
root/bind implementation. Do not claim that all such measures have countable
support. Generic coupling composition / realization requirements, including
the existing gluing boundary, remain explicit. Extending the raw-evaluator
and quotient arguments to this backend is additional work, not an automatic
consequence of the SubEnum proof.

## 4. Raw evaluators, admissibility, and denotation

For SubEnum, reuse the existing total raw evaluator `U_t := free_omega_upper t`
on bounded tests as an auxiliary bridge. It is not the public probability
domain. Define semantic admissibility by existence of a domain value with
exactly this evaluator:

```text
denotes(t, d)  iff forall bounded f, U_t(f) = d(f)
admissible(t) iff exists d : OmegaVal A, denotes(t, d).
```

Equivalently one can package proofs that `U_t` satisfies the domain laws.
Only after proving existence and uniqueness should a proof-parameterized
`denote t Hadmissible` be offered. Do not assign an arbitrary default measure
to invalid raw terms and claim the constructor equations still hold.

Give a sufficient construction certificate, distinct from the extensional
admissibility predicate:

- Ret and Zero are admissible;
- Sample is admissible when the node is a valid subprobability and the
  continuations are admissible on its AE support;
- Lub is admissible when its terms are admissible and their denotations
  increase. Syntactic `free_omega_approx eq` increasingness is a sufficient
  way to discharge this last obligation after order soundness.

Prove bind closure (pointwise first if necessary, with the AE form tracked
explicitly). Zero-mass invalid branches must not become a semantic obstacle.
The extensional predicate, unlike a purely syntactic certificate, should be
closed under existing `sem_eq`.

## 5. Order is not equal-mass coupling

`FOApproxZero` proves `free_omega_approx R FOZero nu` for every `nu`.
Therefore approximation cannot imply ordinary equal-mass coupling: zero
does not couple with a nonzero Dirac measure.

The first endpoint is

```text
admissible mu -> admissible nu ->
free_omega_approx eq mu nu -> denote mu <= denote nu.
```

For general `R`, use a directed test inequality or a genuine subcoupling
whose left marginal is `denote mu` and whose right marginal is bounded by
`denote nu`. Under equality this specializes to information order. Reserve
ordinary coupling (both marginals exact) for `free_omega_qlift` soundness.
Do not use one ambiguous `omega_lift` name for these two contracts.

## 6. Quotient soundness: reuse, then close the real gap

The following **existing source theorems** in
`Backend/SubEnum/FreeOmega/UpperQuotient.v` are useful starting points:

```text
free_omega_qlift_upper_birel
free_omega_qlift_eq_upper
free_omega_qlift_upper_mass
```

They establish bidirectional bounded-test inequalities, evaluator equality
for equality lifting, and mass equality. They do not assert that every raw
term is an additive measure or exhibit a standard joint measure.

Use evaluator equality to transport admissibility and prove
`free_omega_sem_eq_sound`. This avoids a subtle proof trap: `FOQLComp`
quantifies over an arbitrary intermediate raw term. Endpoint admissibility
does not justify an induction hypothesis requiring that intermediate term
to be a probability measure. The existing all-raw functional theorem already
handles intermediate terms without making that assertion.

For actual `free_omega_qlift_sound`, a further realization theorem is required.
On SubEnum, first prove concentration on a countable set (finite supported
sampling plus countable Lub unions), even though the carrier itself can be
uncountable. Then prove a countable coupling/transport theorem turning the
bounded-test inequalities into a joint subprobability measure with exact
marginals and AE relation `R`. This is a substantive obligation. It is not
discharged by simply renaming test inequalities to "standard coupling".
The analogous unrestricted MathComp realization claim must be separately
proved or explicitly qualified; the SubEnum argument is not such a proof.

## 7. Stable-hitting adequacy and the meaning of missing mass

Define the external primitive kernel and its finite stable-hitting iterates
using domain return, bottom and bind. Prove, by induction on fuel, that
interpreting each existing finite approximant gives that external iterate.
This commuting theorem prevents adequacy from being just a second spelling
of the original formal Lub definition.

Then prove finite approximants admissible and increasing, their Lub
admissible, and every complete hitting witness semantically equal to that
domain Lub. The last step uses quotient soundness, not an extra assumption
that an arbitrary chosen hitting witness happens to be admissible.

The target is an unconditional PTree result for an intrinsically bounded
native carrier such as SubEnum, or a result qualified by the established
native-validity / well-formedness condition for a weighted carrier.

Missing mass requires precise wording:

- In general, `1 - mass(H(t))` includes both native subprobability loss and
  failure to reach a stable head through unbounded internal computation.
- For example, sampling the zero subdistribution loses all mass without
  performing an infinite sequence of internal steps.
- With a separate lossless-native premise, the complement can be identified
  with internal nontermination before the next stable observation. A pathwise
  probability claim additionally needs its corresponding operational model;
  the Lub equality alone is not an infinite-path measure construction.
- A stable `Vis` counts as reaching an observation, not terminating the
  entire interactive program. An infinite visible service is not thereby
  assigned zero stable-hitting mass.

## 8. Stages and acceptance gates

| Stage | Deliverable required before pausing |
| --- | --- |
| DS0 (this review) | Independent domain choice; raw-term/admissibility boundary; corrected lifting and missing-mass claims |
| DS1 | Concrete `OmegaVal`, standard-measure correspondence, pointed omega-CPO and both bind continuities; no FreeOmega dependency |
| DS2 | SubEnum native interpretation; raw-evaluator bridge; admissibility/constructor/bind/order theorems; non-increasing Boolean negative test |
| DS3 | Quotient equality soundness and admissibility transport; countable-support and actual coupling realization, with explicit assumptions |
| DS4 | Independent finite-kernel commuting theorem and stable-hitting denotational adequacy for SubEnum; irrational-limit example |
| DS5 | MathComp native adapter and its explicitly scoped FreeOmega soundness results; do not report SubEnum-only results as generic |
| DS6 | Adequacy dependency/liveness review, justified pruning, then Gate D |

Names such as `free_omega_denote_approx`, `free_omega_denote_bind`,
`free_omega_denote_lub`, `free_omega_sem_eq_sound`,
`free_omega_qlift_sound`, and `stable_hitting_denotational_adequacy` remain
proposed endpoint names, **not implemented declarations**. Their signatures
must expose admissibility/backend qualifications until the relevant coverage
theorems discharge them. Completeness, infinite interaction measures, general
WP, arbitrary measurable-space samplers and new interpreter stages are not
acceptance requirements for this work.

For each implementation stage: build and import boundaries; actual compiled
types and `Print Assumptions`; targeted joint kernel checks with stated scope;
positive and negative contract regressions; pause for acceptance. Preserve
the frozen historical source-conservation audits against their accepted
revisions instead of weakening them to tolerate new mathematical edits.

## 9. External anchors and this review's evidence

[Alea's author documentation](https://www.lri.fr/~paulin/ALEA/) describes
bounded expectation functionals with measure laws and continuity, and an
omega-CPO layer. This motivates the presentation, not reuse of its obsolete
Coq implementation or an assertion that the present proofs already exist.

[Isabelle/HOL SPMF](https://isabelle.in.tum.de/library/HOL/HOL-Probability/SPMF.html)
provides the discrete comparison point: `ccpo_spmf`, `bind_lub_spmf`, and
`bind_lub_spmf2` explicitly express order and continuity. Its discrete scope
should not be silently generalized to all MathComp measures.

Local evidence is source inspection of Definition, Approximation,
Observation, Quotient, Measure, the SubEnum upper-expectation/quotient
development, MathComp Kernel, and PrimitiveStableHitting. No new Rocq proof,
build, assumption audit or kernel check is claimed by this documentation-only
review. The raw-Lub obstruction and proposed domain proofs above are design
arguments; implementation and machine checking remain subsequent stages.
